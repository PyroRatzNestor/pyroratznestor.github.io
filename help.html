Quick start

  1. Identify. Open the field dashboard and select the pump / station, controller and drive. Record the model and manual revision.
  2. Choose a path. Use the troubleshooting menus for the symptom, or the tool directory for a known calculation or reference. A dropdown selection alone does not open a troubleshooting topic; press Open Selection.
  3. Measure and compare. Follow the diagnostic prompts and verify assumptions against the installed equipment manual. Calculators do not connect to or control equipment.
  4. Record and prove. Add results to Notes, insert a job card and record the outcome under load. Save notes on this device and export a text backup.

Local storage & backups

There are no portal accounts, shared records or cloud sync. Profiles, saved calculator inputs, checklists and saved notes use this browser's storage on this device. Existing saved data is still available when you use the dashboard on the same website, browser and device.

Save before leaving the dashboard. Notes require Save Notes on This Device. Drive worksheets require their own Save Worksheet action. Unsaved worksheet drafts survive switching dashboard tools, but not a reload or navigation to another page. The dashboard requests a browser warning when notes or worksheets have unsaved changes; do not rely on that warning as a backup.

Export .TXT creates a portable notes backup. Import .TXT adds text to the editor; save the imported notes afterward. Add Worksheet to Notes does not itself save either the worksheet or the notes. Exported notes cannot restore a drive configuration or its structured worksheet.

Clearing site data, private browsing, a different device, or a new website domain can remove or separate local records. Before changing browsers or domains, save and export your notes and retain independent equipment parameter backups. Check for storage error messages.

Safe use

This beta portal supports evidence gathering; it does not authorize electrical work, equipment operation or parameter changes. Follow your employer's procedures, site isolation / lockout requirements and the applicable equipment manual.

Keep commissioned values separate from observations and factory references. Blank means unknown. Do not factory-reset, disable protections or repeatedly restart into a fault based on a calculator or checklist.

Read the source policy and technical limitations.

Access & connectivity

The portal is a static website. Once loaded, its calculations run in the browser without a calculation API. Reliable offline installation and caching are not included yet; do not assume the pages will be available without connectivity.

Directory search filters local starting points. The dashboard's Search Web button sends your entered query to Google in a new tab; manufacturer and training links open external websites. Avoid including confidential site information in web searches.

Use a current browser with JavaScript enabled. The dashboard has a High Contrast button, and pressing / outside an input focuses its web search. Navigation and tools support keyboard use; layouts adapt to smaller screens.

Feedback & corrections

Use the project issue tracker to report a broken link, incorrect reference or tool problem (GitHub sign-in is required to submit). Include the page / tool, expected behavior, observed result and source model / revision / page when applicable. Do not post passwords, customer records or sensitive site information.

For an urgent equipment or safety issue, follow your site's escalation procedure and contact the appropriate qualified service provider rather than waiting for a portal update.
